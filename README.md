# freeCodeCamp Projects

Repository dedicated to projects and challenges developed throughout the [freeCodeCamp](https://www.freecodecamp.org/) certifications.

## Projects

### Machine Learning with Python

- [Rock Paper Scissors](machine-learning-with-python/rock-paper-scissors/) — a Rock Paper Scissors program designed to defeat all four challenge bots with a win rate above 60% against each opponent.
- [Cat and Dog Image Classifier](machine-learning-with-python/cat-and-dog-image-classifier/) — a TensorFlow/Keras convolutional neural network for classifying cat and dog images, built for the freeCodeCamp image-classification challenge.
- [Book Recommendation Engine using KNN](machine-learning-with-python/book-recommendation-engine-knn/) — a collaborative-filtering recommendation system using the Book-Crossings dataset, sparse user-rating features, cosine distance, and scikit-learn K-Nearest Neighbors.

## Organization

Each certification has its own directory, and every project is kept in a separate folder containing its source code, notebook, and corresponding tests or evaluation logic.
